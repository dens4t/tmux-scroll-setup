# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-29

### Added
- Initial release
- Mouse scroll support enabled by default
- Scrollback buffer of 50,000 lines
- Vi mode for copy mode
- 256 color support
- Clipboard integration
- Auto-installation script
- Comprehensive README with examples
- Cheatsheet for quick reference
- Test script for configuration verification
- Bash aliases for common tmux commands
- MIT License

### Features
- Full mouse wheel scrolling in tmux
- Keyboard navigation with vi keys
- Copy and paste functionality
- Optimized for web terminals (ttyd, pi.dev)
- Works seamlessly with SSH sessions

### Documentation
- Complete setup guide
- Troubleshooting section
- Multiple scrolling method examples
- Window and pane management guide
- Session management tips
